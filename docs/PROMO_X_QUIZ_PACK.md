## Q1. FT バブルの罠（BTN 3BB が隣にいるのに AJo でコールする？）

添付画像: `quiz-1-bubble.png`

### 本投稿
```
【ICMクイズ #1】これコール？フォールド？

残り4人・3人入賞（50 / 30 / 20）
SB 0.5 / BB 1 / アンティ 1

・BB（自分）12BB
・SB（相手）22BB
・CO 18BB
・BTN 3BB（超ショート！）

SBが上位40%でオールイン。
自分の手は AJo（相手レンジに勝率 60.1%）。

勝率60%あるけど、コールする？
答えはリプ欄👇

#ポーカー #ICM
```

### リプ1（答え・解説）
```
答え：❌ フォールド

・チップだけの必要勝率：43.5%（余裕のコール）
・厳密 ICM の必要勝率：69.2%（RP +25.8% / BF 2.80）

AJo（60.1%）でも 88（59.3%）でも大損のフォールド。
理由は隣に 3BB の超ショートがいるから。自分が飛ばなければ入賞が濃厚なので、負けた時の痛みが勝った嬉しさの 2.8 倍になります。
```

### リプ2（アプリ導線）
```
この数字は自作の iOS アプリ「Poker ICM」で厳密 ICM 計算しています（4人卓まで無料・完全オフライン）。
自分の卓のスタックを入れてそのまま確かめられます👇
https://apps.apple.com/jp/app/id6793358140
```

## Q2. PKO バウンティの魔力（同じ局面でも首の額で正答が逆転する）

添付画像: `quiz-2-bounty.png`

### 本投稿
```
【ICMクイズ #2】PKOでどこまで広くなる？

残り3人・賞金 50 / 30 / 20（アンティ 1）
・BB（自分）18BB（首 10）
・SB（相手）14BB（首 25）
・BTN 20BB（首 15）

SBが上位30%でオールイン。自分の手は KTs（勝率 47.7%）。

① バウンティなしなら？
② PKO（相手の首 25）ありなら？

答えはリプ欄👇

#ポーカー #PKO #ICM
```

### リプ1（答え・解説）
```
答え：
① バウンティなし → ❌ フォールド（必要勝率 49.8% / BF 1.19）
② PKO あり → ✅ コール（必要勝率 42.5% / BF 0.88）

自分が相手をカバーしていて飛ばせるので、必要勝率が 7.3pt も下がります（チップEVの 44.8% よりさらに低い！）。
バウンティなしでは降りる KTs や A7o も、PKO なら余裕のコールになります。
```

### リプ2（アプリ導線）
```
KO / PKO のバウンティ計算も Poker ICM（iOS）に入れました。
カバーしている相手には BF マップが緑になるので、誰を狙えるかひと目で分かります👇
https://apps.apple.com/jp/app/id6793358140
```

## Q3. サテライトの掟（QQ でも降りる局面）

添付画像: `quiz-3-satellite.png`

### 本投稿
```
【ICMクイズ #3】これ QQ 降りられる？

残り5人・上位3人が同額通過のサテライト（33 / 33 / 33）
SB 0.5 / BB 1 / アンティ 1

・BB（自分）22BB（2番手）
・SB（相手）28BB（チップリーダー）
・BTN 18BB / CO 15BB / UTG 5BB

SBが上位40%でオールイン。
自分の手は QQ（勝率 72.5%）。

コール？フォールド？
答えはリプ欄👇

#ポーカー #ICM #トーナメントポーカー
```

### リプ1（答え・解説）
```
答え：❌ フォールド

・チップだけの必要勝率：46.5%
・厳密 ICM の必要勝率：74.6%（RP +28.1% / BF 3.42）

勝率 72.5% の QQ ですらフォールド。コールできるのは AA（85.7%）と KK（78.2%）だけです。
サテライトでは「1位になる意味」がなく「残ること」が全てなので、2番手がチップリーダーとぶつかるのは最悪の勝負になります。
```

### リプ2（アプリ導線）
```
こういうサテライトや FT バブルの「感覚がバグる局面」、オフラインでサッと確かめたくて iOS アプリを作りました👇
https://apps.apple.com/jp/app/id6793358140
```

### 本投稿
```
【ICMクイズ #4】2番手が一番きつい

残り4人・3人入賞（50 / 30 / 20・アンティ 1）
・BB（自分・2番手）18BB
・SB（相手・CL）24BB
・BTN 6BB / CO 5BB

ショートが2人いる状況で、CL の SB が上位40%でオールイン。

コール？フォールド？
答えはリプ欄👇

```
答え：❌ フォールド

・厳密 ICM の必要勝率：73.1%（RP +27.4% / BF 3.10）

5BB・6BB のショートが2人残っているので、2番手が CL に挑んで4位で飛ぶ損失が巨大すぎます。これが「2番手 vs CL は BF が最大になる」の典型です。

## Q6. 3人同時オールイン（BTN オールイン → SB コール → BB の AKs は？）

添付画像: `quiz-6-overcall.png`

### 本投稿
```
【ICMクイズ #6】3人同時オールインの罠

残り3人・賞金 50 / 30 / 20（アンティ 1）
全員 10BB。

① BTN がオールイン（Nash 37.6%）
② SB がそれにコール（Nash 8.7%）
③ BB の自分の手は AKs。

オーバーコールする？降りる？
答えはリプ欄👇

#ポーカー #ICM #Nash
```

### リプ1（答え・解説）
```
答え：❌ フォールド（3人同時オールイン Nash 計算）

SB が降りていれば BB は 14.9% でコールできます。
でも SB がすでにコールしたあとの BB のオーバーコールレンジは、なんと 1.8%（JJ+ のみ）！

AKs でもフォールドが均衡。理由はシンプルで、自分が降りてBTNとSBのどちらかが飛んでくれれば、無傷で2位以上（賞金 30% 以上）が確定するからです。
```

### リプ2（アプリ導線）
```
普通の2人用ツールだと出せない「3人同時オールイン（オーバーコール）」まで、端末内だけで Nash 計算する iOS アプリを作っています👇
https://apps.apple.com/jp/app/id6793358140
```
