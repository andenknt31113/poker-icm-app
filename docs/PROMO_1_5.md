### A. メイン告知（画像4枚を添付・固定ポスト候補）

```
ポーカーのトーナメント向け ICM 計算アプリ「Poker ICM」（iOS）を作っています。

・スタックと賞金を入れると、必要勝率・RP・BF がその場で出る
・全員ぶんの Nash レンジ一覧（3人同時オールインまで）
・13×13 ハンド表（タップで数値確認）
・バウンティ（KO / PKO）と ICM チョップにも対応

4人までの卓と例題は無料でそのまま使えます。計算は完全オフライン👇
```

リプライに続ける：

```
https://apps.apple.com/jp/app/id6793358140

オールインが絡む判断に特化しています（2BB オープンやリンプは扱いません）。5人以上の卓の編集・局面保存・バウンティ計算だけ買い切りの Pro です。計算の前提と限界もアプリ内にまとめています。
```

### B. バウンティ（KO / PKO）切り口（card-2-bounty を添付）

```
KO / PKO トナメで「相手を飛ばせるならどこまで広くコールしていいか」、感覚だけだとズレやすいので Poker ICM に入れました。

各プレイヤーのバウンティ額を入れると、必要勝率・ハンド表・Bubble Factor・Nash に全部反映されます。カバーしている相手には BF が 1.0 を下回って緑になります。

#ポーカー #ICM #PKO #個人開発
```

### C. 例題クイズ型（card-1-main を添付・週1〜2回の継続投稿向け）

```
残り4人・賞金 50 / 30 / 20。
自分は BB で 4BB、SB が 18BB からオールイン。

コールに必要な勝率は？

・チップだけで考えると 28.6%
・ICM 込みだと 33.5%（RP +4.9%）

この +4.9% がバブルの重みです。
自分の卓のスタックを入れてそのまま確かめられます（iOS・4人卓まで無料）。
```

### D. Nash 一覧の紹介（card-3-nash を添付）

```
ショートスタックのオールイン判断、自分の手だけじゃなく「誰がオールインするか × 後ろ全員のコール」を一覧で見たくて作りました。

Poker ICM の Nash タブでは、後ろの全員のコールと「1人コールしたあとにもう1人が入るオーバーコール」まで1画面に並びます。行をタップすると 13×13 の表も開きます。
```

### E. 作った理由・個人開発ストーリー型

```
店舗トナメのバブルで「これコールしていいんだっけ…」を毎回あいまいに決めていたので、オフラインでサッと確かめられる iOS アプリ「Poker ICM」を作りました。

必要勝率は近似ではなく厳密な ICM で計算しています。まだまだ磨き中ですが、もし触って役立ったら App Store の評価をもらえるとすごく励みになります！
```
