## ASC Campaign Link（`ct=x_jp`）差し替え手順

各投稿本文には、そのまま即コピペして投稿できる日本向け App Store URL（`https://apps.apple.com/jp/app/id6793358140`）を入れている。X 経由の DL・課金数を App Store Connect で計測するため、予約設定前に以下の手順で Campaign Link へ差し替えることを推奨する。

1. **App Store Connect → App Analytics → ソース → キャンペーンリンクを生成** を開く。
2. キャンペーン名（`ct`）に `x_jp` を指定してリンクを発行する（自分の Provider Token `pt=<provider>` と `mt=8` が自動付与される）。
   - 例: `https://apps.apple.com/jp/app/id6793358140?pt=<provider>&ct=x_jp&mt=8`
3. 下記各リプ（および固定ポスト）の `https://apps.apple.com/jp/app/id6793358140` を、発行した Campaign Link に一括置換して予約投稿する。
   - **文字数への影響なし**: X では URL はパラメータ長に関わらず一律 **23 ウェイト**換算のため、差し替えても 280 ウェイト上限を超えない。
   - **最小集計閾値対策**: キャンペーン枠は増やしすぎず、`x_jp` / `x_en` / `reddit` / `poster` / `web` の 4〜5 枠に集約する。
