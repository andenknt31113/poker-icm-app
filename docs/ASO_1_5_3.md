## 2. 1.5.3 差し替え案（文字数チェック済み）

App Store の検索重みは `name` > `subtitle` > `keywords`。すでに上位の `name` は維持し、`subtitle` にバウンティ系を引き上げつつ `keywords` の重複を削って 100 文字枠を最大化する。

### 日本語（ja）

- **アプリ名**（据え置き・25/30字）:
  ```
  Poker ICM - ポーカー トーナメント計算
  ```
- **サブタイトル**（23/30字）:
  ```
  必要勝率・Nashレンジ・バウンティ・チョップ
  ```
  ※ `バウンティ` を直接サブタイトルに昇格。`計算` はアプリ名にあるため省略し、検索重みと一覧性を両立。
- **キーワード**（99/100字・重複なし）:
  ```
  PKO,KO,バブルファクター,ナッシュ,プッシュフォールド,テキサスホールデム,MTT,SNG,プリフロップ,ディール,オールイン,リスクプレミアム,賞金,トナメ,サテライト,オフライン,ソルバー
  ```
  ※ `GTO` は「2BB オープンも計算するアプリ」との誤解を避けるため外し、`PKO,KO,サテライト,オフライン` を追加。
- **プロモーションテキスト**（90/170字・審査なしでいつでも更新可）:
  ```
  4人までの卓と例題は無料。厳密ICMの必要勝率・全員ぶんのNash（3人同時オールイン対応）・バウンティ(KO/PKO)・ICMチョップを完全オフラインで計算。買い切りPro対応。
  ```

## 3. 反映のタイミングと運用

1. **プロモーションテキスト**: 今すぐ（審査なしで）ASC から反映可能。
2. **サブタイトル（`appInfoLocalizations`）とキーワード（`appStoreVersionLocalizations`）**: `1.5.3` のバージョン作成〜審査提出時にまとめて PATCH する。
