# 2026-10-01 入力と分析の改善

## 方針

1.2のコンパクトなプレイヤー入力を基準とする。過去の依頼で削除した案内カード、独立した手札選択、サマリーの賞金取り分は復活させない。入力と結果までの距離を短くし、判断できない状態で以前の判定を残さない。

## 今回の変更

- 大きな紹介文を削除。例題は初回に閉じ、スマホの初期画面からプレイヤーを入力できる。既存の開閉設定は保持。
- 横並びの入力、短い説明、自分・相手の行の色分け、入力の読み上げラベル。「元に戻す」は見出しの横へ移動。
- 「自分 ⇄ 相手」をセットアップとNashに追加。人物・スタック・ポジションは動かさず役割を交換。通常の役割選択でも両者の指定を維持する。
- 人数変更時の無効・重複ポジションを修復。未指定だけの卓には勝手に位置を割り当てない。取り消しはポジション自動連動の状態も復元。
- 5人以上の編集ロックの理由を説明。無料の4人編集、例題の分析、人数を減らす操作は維持。
- 分析のナビゲーションを「レンジ比較」「賞金・BF」「Nash」へ短縮。自分の結果を先に表示し、相手表と凡例は開閉式。カスタム編集時は相手表を開く。
- 賞金合計0、自分・相手未指定、当事者0BBでは結果を隠して修正理由を表示。空のカスタムレンジではコール可能率を出さない。入力修正で計算表示を復帰。
- Nashの賞金・ブラインド・残りのプレイヤーを詳細にまとめる。プッシュ役と行動順が逆の場合は案内。Nash内の役割交換も自動再計算する。
- スクロールでサマリーを縮めたときの位置の変動と、下部メニューがハンド表のタップを妨げる問題を修正。

## 確認結果

- 単体321件（core 77件、playground 244件）成功。
- 画面操作16件成功。初回表示、役割交換・取り消し、人数変更、入力修正、空レンジ、無料/Pro境界、保存復元、練習、Nash自動更新、日本語/英語を確認。
- 320 / 390 / 768 / 1280pxで横はみ出しなし。型チェック・通常の無料/Pro構成のビルド・差分の空白検査成功。
- `artifacts/usability-2026-10-01/` に画像を保存し、小型スマホ・デスクトップの入力と分析・Nashを目視確認。
- ローカルのE2Eは `E2E_BROWSER_CHANNEL=chromium npm -w @poker-icm/playground run e2e` で実行。以前タイムアウトしたheadless shellではなく、インストール済みChromiumを使用。
- 計算モデルを変更する作業ではない。自動テストと画面確認はiOS実機の検証とは区別する。

## リリース前の残件

今回の変更はローカル版。アップロード済み1.3(1)への反映、ストア画像更新、審査提出は行っていない。最新版のiOSビルド作成、実機のキーボード・購入復元・オフライン起動・1.2からのデータ移行確認が必要。以前のリリース説明の「席順編集」「賞金取り分」は現在のUIと一致しないため、そのまま使用しない。
